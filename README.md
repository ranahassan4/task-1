# Online Security Knowledge Graph

This project visualizes a mini knowledge graph focused on key concepts in online security using Python libraries.

## 📌 Project Overview

The graph represents relationships between online security elements such as:

- **Password → protects → Account**
- **Two-Factor Authentication → adds → Security Layer**
- **Phishing → targets → Personal Information**
- **Firewall → filters → Network Traffic**
- **Encryption → secures → Data**

The graph uses curved lines and yellow-colored nodes for clear, structured visualization.

## 🛠️ Technologies & Libraries Used

- Python 3.x
- NetworkX
- Matplotlib
